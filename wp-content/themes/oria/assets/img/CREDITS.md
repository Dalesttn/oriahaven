# Picture credits

Where the photographs the theme ships came from, so the answer exists in
one place rather than in whoever's memory built the page.

Pexels photographs are free to use, commercially, without permission and
without attribution. Crediting anyway is the decent thing and it costs
nothing — and if a picture ever has to be replaced, this file is how you
find out what it was and go looking for something like it.

## App icons

`oria-apps/assets/icons/*.webp` are each app's own icon, fetched from
Apple's public lookup endpoint and stored locally rather than hotlinked.
They identify the app being reviewed and belong to their developers.
